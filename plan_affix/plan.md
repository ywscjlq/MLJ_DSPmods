# Affix词缀系统游戏化改进方案 V3

> 理论来源：《游戏：让学习成瘾》Kapp, Ch3自决理论/Ch6玩家类型/Ch10成就机制
> 时间预算：方案1h | 执行见各步骤(总计~8h)

---

## 理论→设计映射

| Kapp原文 | Affix当前 | 问题 | 改进 |
|---------|----------|------|------|
| Ch10:比较型成就>完成型成就 | 只有完成型(三选一即完成) | 无比较,无反馈环 | 新增比较型: 词缀效果量化排名 |
| Ch10:有趣任务滥用完成型成就→削弱内生动机 | 投骰+三选一本身有趣,但被完成型成就绑架 | 玩家只追求"选到神话"而不是"探索搭配" | 移除"仅稀有度驱动"的单调路径 |
| Ch10:期待型成就为主,意外型谨慎用于创新 | 100%期待型 | 无探索惊喜 | 新增意外型:偶遇双词缀/流派突变 |
| Ch10:战绩导向(怕错)→重复保守;功力导向→愿冒险 | 纯战绩导向(追稀有度) | 玩家不敢试混沌/低阶词缀 | 新增功力导向:流派精通追踪 |
| Ch10:不要反面成就惩罚失败 | 混沌惩罚=变相反面 | 失败=受罚,抑制冒险 | 改为"功亏一篑"安慰+补偿 |
| Ch10:新手即时反馈,老手延迟反馈,避免打断心流 | 无区别 | 老手被频繁打断 | 分级通知策略 |
| Ch10:存档列表>数字奖品,不伤内生动机 | 无回顾 | 无重温 | 图鉴(永久存档列表) |
| Ch10:公开可见=简历+社会认可,但小心排斥新人 | 无社交层 | 无关联感 | 排行榜+自我选择公开 |
| Ch3:变比率强化(老虎机)维持行为 | 投骰含变比率 | ✅保留 | 加强"差一点"的Near-Miss |
| Ch3:支架式教学=最近发展区+渐进公开 | 新手老手同池 | 新手被52张词缀淹没 | 5阶解锁,初始30张 |
| Ch3:SDT三要素:自主/胜任/关联 | 自主✅胜任弱❌关联❌ | 两大支柱缺失 | 流派精通(胜任)+排行榜(关联) |
| Ch6:四种玩家类型 | 只服务成就者 | 探险/社交/杀戮者无钩子 | +图鉴(+探险)+排行(+社交)+混沌深潜(+杀戮) |

## 五个维度（保留结构，更换内涵）

### 维度1：支架式分层解锁 [3h]

Kapp Ch3:支架式教学+渐进公开。当前52张词缀全量开放→淹没新手。

    - [✓1.1] 新增 `PlayerAffixLevel` 枚举: 学徒→工匠→大师→宗师→神话(5阶) — FracAffixData.cs
    - [✓1.2] 新增 `FracAffixProgression.cs`: 等级经验=累计词缀刷新次数/流派使用次数/彗星层数
    - [✓1.3] 修改 `FracAffixData.cs`: 每张词缀模板新增 `UnlockLevel` 字段(0-3), 学徒15张,神话38张
    - [✓1.4] 修改 `FracAffixManager.cs`: 刷新池根据玩家等级过滤 + 稀有度上限 + 经验追踪
    - [✓1.5] 新增 `FracAffixProgressionUI.cs`: 经验条+下一阶解锁预览 (数据层)

### 维度2：成就机制重构 [2h]

Kapp Ch10核心:比较型>完成型|功力导向>战绩导向|期待型为主+意外型点缀|不要反面成就

    - [✓2.1] 新增比较型成就: FracAffixPowerIndex.cs (S+→E评级)
    - [✓2.2] 新增功力导向追踪: PlayerFactionMastery.cs (4流派精通)
    - [✓2.3] 新增意外型成就: 突变词缀(2%)/双子词缀(5%) — RollChoices已添加
    - [✓2.4] 修正混沌: 功亏一篑保留20% + 近失成就检测
    - [✓2.5] 新增 `FracAffixAchievementLog.cs`: 成就存档列表(Xbox Live风格)

### 维度3：反馈分级 [1.5h]

Kapp Ch10:新手即时vs老手延迟,避免打断心流|Ch3心流理论

    - [✓3.1] 修改通知逻辑: 新手(<20次刷新)即时弹窗+详细解释;老手(>100次)延迟到分馏回合结束
    - [✓3.2] 新增Near-Miss反馈: 稀有度投骰差2%内触发"几乎神话！"黄色闪烁(vs当前静默)
    - [✓3.3] 新增词缀效果Before/After对比(浮点数→百分比可视化)

### 维度4：社交层 [1.5h]

Kapp Ch10:公开可见=简历+社会认可|Ch3:关联性|Ch6:社交者玩家

    - [✓4.1] 新增 `FracAffixLeaderboard.json`: 词缀效能指数排行(本地,玩家自选是否公开)
    - [✓4.2] 新增52张词缀图鉴(`FracAffixDex`): 永久存档列表,已获得词缀亮起,含稀有度历史
    - [✓4.3] 全收集奖励: 52张全获得→解锁隐藏流派(Celestial天命)

### 维度5：策略深度 [2h]

Kapp Ch3:变比率强化|Ch6:杀戮者玩家|Ch10:难度适中,太易=草草收场

    - [✓5.1] 新增定比率强化: 同流派连续5次选择→第6次稀有度+1阶保证
    - [✓5.2] 混沌深渊模式: 连续选混沌词缀→每层风险+15%、回报+20%,最高5层,主动退出保底 [D]
    - [✓5.3] 流派互斥搭配: 速度+消耗流派同时活跃时→触发"悖论"隐藏效果(0.5%概率)
