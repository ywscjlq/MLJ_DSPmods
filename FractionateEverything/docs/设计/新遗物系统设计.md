# 远古遗物系统设计 (v3.0.0 原生版)

## 设计目标

- **轻量**：不搬旧代码，不引入新依赖，不改上游管道
- **融入**：遗物从"协议完成"自然产出，不走打黑雾
- **获得感**：每完成一个协议都有"抽卡"惊喜
- **深度**：收集动机 + 套装共鸣

## 核心循环

```
协议完成（现有）
    │
    ├── 产出 +2 记忆源点（现有）
    │
    └── 50% 概率产出 🏺 远古遗物碎片（新）
                │
                ├── 碎片积累至 3 枚
                │       ↓
                │   自动合成 1 个遗物 🎁
                │       ↓
                │   RecipeModifierCache 追加全局加成
                │
                └── 收集特定遗物组合
                        ↓
                    自动激活共鸣加成
```

## 掉落规则

| 条件 | 碎片数量 |
|:----|:--------:|
| 发现即完成 (discovery ≥ 100) | 2 |
| 推进后完成 | 1 |
| 锚定检索完成 | 额外 +1 |

- 推进后完成基础 50% 概率出碎片
- 锚定检索完成 **必出** + 额外 1 枚
