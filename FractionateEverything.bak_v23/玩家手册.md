# FractionateEverything 玩家手册 v2.0

## 一、核心概念

### IFE残片（物品ID:8060）
- **唯一的货币**。所有交易、自动补货都用它结算。
- 来源：卖掉多余物品换取残片；或通过精馏塔等设施产出。
- 不占用背包格子，存储在"数据中心"（类似星际物流的独立库存）。

### 交易所
- 类似真实股票市场：每件物品有 BidPrice（买价/你卖出给系统的价格）和 AskPrice（卖价/你买入的价格）。
- 价差约4%——Bid = Mid×0.96, Ask = Mid×1.04。
- 价格随买卖量浮动：大量买入推高价格，大量卖出压低价格。
- 每60秒刷新一次定价。

## 二、解锁流程

| 阶段 | 条件 | 解锁内容 |
|------|------|----------|
| **0** | 开局即可 | 精馏塔（配方） |

> 用残片直接买黄糖可立即解锁交易所（绕过科技树限制）。

## 三、交易所操作

### 面板路径
主面板 → 「交易所」标签

### 基本操作
1. **买入**：输入数量，点击"买入"。扣除残片，物品进入数据中心。
2. **卖出**：输入数量，点击"卖出"。物品从数据中心扣除，获得残片。
3. **查看行情**：市场板展示所有可交易物品的 MidPrice 涨跌。

### 价格规则
- 初始价格 = 物品 baseValue ±30% 随机偏移（模拟市场发现）
- 每60秒调整一次，当前价格 = 60%×旧价 + 40%×供需价（R5加速响应）
- 价格范围：baseValue × 0.55 ~ 1.35
- 储存价值物品（建筑/高级材料）最低不低于 baseValue × 0.90

### 残片兑换（保底）
- 当某个物品交易所未上架或你不想等市场波动时使用
- 价格 = baseValue × 安全溢价 × 阶段权重
  - 安全溢价：同阶段 1.15× ~ 跨阶段 1.60×（R4降价）
  - 越晚期的物品越贵

## 四、自动补货 ⭐核心玩法

### 面板路径
主面板 → 「自动补货」标签

### 功能说明
自动补货是你设置"我想保持XX物品至少NNN个"，系统自动从交易所买入。

### 可配置参数

| 参数 | 默认值 | 说明 |
|------|---------|------|
| 目标数量 | 手动设置 | 低于此数量自动买入 |
| 启用/禁用 | 启用 | 暂停该物品的自动补货 |
| 补充上限 | totalBudget(80%碎片) | 每市场周期内最多花多少残片 |
| 限价倍数 | 2.5× | AskPrice > MarketValue×2.5 时不买 |
| 超出抛售 | 自动(target×3) | 库存超过此数自动卖出 |

### 执行流程（每30秒一轮）
```
遍历所有启用物品（建筑优先）：
  1. 当前库存 < 目标? → 继续
  2. 累计花费超预算? → 跳过，等下轮
  3. 价格超限价? → 跳过
  4. 执行购买（静默，不弹窗口）
  5. 库存 > 抛出上限? → 自动卖出（BidPrice<开盘价30%则止损暂不卖）
```

### 自动扫描
- 每10秒扫描一次"常用物品"（库存>0且交易所挂牌的）
- 每100秒强制全量扫描所有交易所物品，确保新解锁建筑不遗漏

### 预算机制
- totalBudget=0 时：自动预算 = 当前残片数 × 70%
- 每次市场升级触发"里程碑奖励"：3个周期内预算+20%（=残片×84%）
- totalBudget>0 时：使用你设定的固定预算
- 预算跨市场周期累计，市场刷新时重置

### 储备碎片
- 自动时：保留 max(100, 碎片数÷10) 的碎片不用于购买
- 手动设置时：使用你设定的固定储备量

## 七、经济系统

### MarketValue（基础价值）
- 每个物品有一个 baseValue，来自原版DSP数据。
- 动态因素：该物品在你工厂的产能/消耗比影响 0.55~1.35 倍率。
- 价值每60秒更新一次。

### Bid/Ask 价差
```
MidPrice = MarketValue × 当前倍率
BidPrice = max(1, MidPrice × 0.96)   ← 你卖出时系统给你的
AskPrice = max(1, MidPrice × 1.04)   ← 你买入时要付的
```

### 出货量（Throughput Factor）
- 高流通物品价格更稳定（0.95~1.05）
- 低流通物品价格波动更大

## 八、实用技巧

1. **刚解锁时**：手动在交易所买卖几次建立价格基准
2. **建筑优先**：自动补货先处理建筑物品，生产线不容易断
3. **预算别设太高**：首次设 500-1000，观察一轮（60秒）花费后再调
4. **超出抛售**：设为 target×3 即可，多余库存自动变现
5. **残片不够?** 在残片兑换用最低溢价兑常用物品，别在交易所高价买
6. **价格异常?** 等60秒市场刷新，或者去看市场板确认是否低流通物品

## 九、市场事件

市场每轮刷新时可能触发随机事件（概率 = 等级×1.5%/轮）：

| 事件 | 价格因子 | 持续 | 说明 |
|------|----------|------|------|
| 🥇 淘金热 | 1.5× | 5轮 | 卖出大赚，适合变现 |
| 🧨 恐慌抛售 | 0.7× | 3轮 | 买入抄底好时机 |
| 📦 大单求购 | 1.3× | 2轮 | Lv7+解锁，价格温和上涨 |
| 🦢 黑天鹅 | 2.0×/0.5× | 1轮 | 50%暴涨50%暴跌，赌运气 |
| 📰 市场快报 | — | 1轮 | 瞬时行情播报，不改变价格 |
| 🎲 丰收季 | 0.65× | 6轮 | 折扣幅度温和但窗口长，适合计划性采购 |

> 事件针对随机单个物品生效，不是全市场。

## 十、常见问题

**Q: 自动补货不触发?**
A: 检查 ①物品已启用 ②目标>库存 ③预算>0 ④价格<限价 ⑤有足够储备碎片

**Q: 碎片怎么获得?**
A: ①卖出多余物品(通过交易所或自动补货超出抛售) ②精馏塔产出 ③Dark Fog战利品

**Q: 交易所物品太少?**
A: 等待自动扫描补充，或手动在自动补货面板添加物品ID

**Q: 价格一直在涨?**
A: 大量买入推高价格。减少单次购买量，分多次小额买入。
